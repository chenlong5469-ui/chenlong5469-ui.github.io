# mhzb · 梦幻西游收支账本

基于「梦幻西游收支明细.xlsx」制作的**可编辑**在线记账静态页面。

## 功能

- 📊 汇总卡片：游戏总支出 / 变现总收入 / 实际净投入（实时计算）
- ✏️ 可编辑：新增 / 编辑 / 删除，按分类自动分组并显示小计
- 💾 本地持久化：数据保存在浏览器 localStorage，刷新不丢
- ⬇⬆ 备份迁移：一键导出 / 导入 JSON
- ↺ 一键重置：恢复为初始 Excel 数据
