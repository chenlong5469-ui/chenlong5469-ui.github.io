# mhzb · 梦幻西游收支账本

基于「梦幻西游收支明细.xlsx」制作的**可编辑**在线记账静态页面,托管于 GitHub Pages。

## 在线访问

**https://chenlong5469-ui.github.io/mhzb/**

## 功能

- 📊 汇总卡片:游戏总支出 / 变现总收入 / 实际净投入(实时计算)
- 📑 支出明细 / 变现收入 双视图切换,按分类自动分组并显示小计
- ✏️ 可编辑:新增 / 编辑 / 删除
- 💾 本地暂存:修改写入浏览器 localStorage,刷新不丢(xlsx 未变时)
- 📤 导出 Excel:一键生成 `MHXY.xlsx`(三表结构,可被本页重新读回)
- ⬇⬆ JSON 备份:导入 / 导出,便于跨设备迁移

## 目录结构

```
.
├── index.html          # 账本主页面(内嵌 CSS + JS,引用 CDN 版 SheetJS)
├── now/
│   └── MHXY.xlsx       # ⭐ 权威数据源(三表:支出明细表 / 游戏变现收入明细表 / 成本核算汇总表)
├── .nojekyll           # 跳过 GitHub Pages 的 Jekyll 处理
└── README.md
```

## 数据流(关键)

**数据源只有一个:`now/MHXY.xlsx`。** 页面每次打开都会 `fetch` 这个文件并用 SheetJS 解析。

### 日常更新流程(改账后上线)

1. 在页面上增删改条目(暂存在浏览器本地)
2. 点 **「📤 导出 Excel」** → 下载新的 `MHXY.xlsx`
3. 用它**覆盖**仓库里的 `now/MHXY.xlsx`
4. `git add && git commit && git push`
5. 刷新网页即可看到新数据

页面打开时会把当前 xlsx 的内容算一个"签名"存进本地;之后你只要不替换 xlsx,页面的本地编辑会一直保留;一旦 xlsx 被更新(签名变化),刷新后会自动采用新 xlsx 的数据。

### 离线/异常降级

若在线 xlsx 暂时取不到(网络/路径问题),页面会自动回退到浏览器里的本地副本,不影响查看。也可用 **「🔄 从 xlsx 重新载入」** 强制重新拉取。

## xlsx 格式约定

`now/MHXY.xlsx` 需包含以下三个工作表(列顺序固定):

- **支出明细表**:表头 `分类 | 明细项目 | 金额 (元) | 备注`;以 `▌分类名` 开头的行作为分组标题;含 `小计/合计` 的行会被自动跳过
- **游戏变现收入明细表**:表头 `收入分类 | 变现项目 | 金额 (元) | 备注`
- **成本核算汇总表**:自动计算,无需手填

页面导出的 xlsx 完全符合此格式,覆盖即可,无需手动编辑。
